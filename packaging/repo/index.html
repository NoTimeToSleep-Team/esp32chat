Local Chat — package repository

Self-hosted chat server for a private network. Signed apt, dnf and pacman repositories.

Debian / Ubuntu / Raspberry Pi OS

curl -fsSL https://notimetosleep-team.github.io/esp32chat/setup-apt.sh | sudo sh

Afterwards: sudo apt install local-chat, updates with sudo apt upgrade.

Fedora / RHEL-compatible

sudo dnf install https://notimetosleep-team.github.io/esp32chat/rpm/local-chat-release-1-1.noarch.rpm
sudo dnf install local-chat

Arch Linux

curl -fsSL https://notimetosleep-team.github.io/esp32chat/setup-arch.sh | sudo sh

Afterwards: sudo pacman -S local-chat, updates with sudo pacman -Syu.

After installation

sudo lc setup     # create the administrator and configure the server
lc status         # check the service
sudo lc logs      # logs

Source, documentation and issues: github.com/NoTimeToSleep-Team/esp32chat. Signing key: local-chat.gpg.
