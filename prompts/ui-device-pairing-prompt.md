## Контракт API

Веб-часть (для UI):

- `POST /devices/api/pair/claim` — тело `{session_token, code}`.
  Успех: `{status:"ok", device:{device_id, device_type, name, paired_at_ms}}`.
  Ошибки: `404 code_not_found`, `410 code_expired`, `409 already_paired`, `403 guest_blocked`.
- `GET /devices/api/pair/list?session_token=...` — уже существует, вернёт список привязанных устройств.
- `POST /devices/api/unpair` — уже существует, `{session_token, device_id}`.

Для справки (это вызывает устройство, UI не касается):

- `POST /devices/api/pair/request` `{device_id, device_type, name}` → `{pairing_id, code, expires_at_ms}`
- `GET /devices/api/pair/status?pairing_id=...` → `{status: "pending|paired|expired"}`

Код живёт 5 минут, одноразовый.
