# План развития чатов (ориентир — Telegram)

Дата: 2026-09-23. Статус: **только исследование**, код не менялся (кроме фикса поиска гостей).

## 1. Что уже есть в проекте

### Данные (`server/migrations/0004_chat_core.sql` + поздние миграции)
- `chats`: `id`, `kind` (`common` | `custom`), `title`, `description`, `owner_user_id`, `created_at_ms`, `updated_at_ms` + добавленные позже `is_private`, `room_code_hash`, `avatar_url`.
- `chat_members`: `chat_id`, `user_id`, `role` (`owner` | `member`), `joined_at_ms`.
- `chat_messages`: текст, автор, `client_message_id`, правка, вложения (через media).
- `ChatRoom` уже содержит `avatar_url`, `has_room_code`, `owner_user_id` — под профиль чата почти всё есть.

### API
| Endpoint | Что делает |
| --- | --- |
| `POST /chat/api/chats` | создать чат (`title`, `description`) — **без участников** |
| `GET /chat/api/chats` | список чатов пользователя |
| `POST /chat/api/chats/{id}/members` | добавить участника (есть!) |
| `POST /chat/api/chats/{id}/members/bulk` | добавить всех (только админ) |
| `GET /chat/api/private/{id}/members` | список участников (работает и для обычных чатов) |
| `POST /chat/api/private/{id}/config` | правка названия/описания/аватара/кода — **только для private-чатов** |
| `GET /chat/api/users/search` | поиск людей (гостей теперь не показывает) |
| `POST /chat/api/dm` | личка |
| `POST /chat/api/private` + `/join` | приватные комнаты по коду |

### UI
- Модалка «New Chat»: только название и описание (английские подписи, без выбора людей).
- Шапка чата → модалка «инфо»: только ID, описание, «обновить» (read-only).
- Нет: добавления/удаления участников, выхода из чата, удаления чата, аватара чата, ролей в интерфейсе.

## 2. Найденные проблемы
1. При создании чата нельзя добавить людей (создаётся пустой чат, участник = только создатель).
2. Гости (`role='guest'`) появлялись в поиске для лички — **исправлено** (сервер + UI).
3. В поиске людей индикатор статуса всегда серый: API не отдавал `status`/`role` — **исправлено** (теперь показывается бейдж админа/модератора).
4. Нет управления участниками и профиля чата.
5. Нет разделения на группы и каналы (есть только `common` = общий чат и `custom` = созданный пользователем).
6. Нет выхода из чата и удаления чата владельцем.
7. Названия/подписи в модалках чата частично английские.

## 3. Что просил пользователь и как это делается

### 3.1. Создание чата с обязательным участником
- API: `POST /chat/api/chats` принимает `member_ids: list[int]` (≥1), валидация: активный, не гость, не сам создатель → 422 `members_required`.
- Сервис: `create_custom_chat(..., member_ids=...)` — после вставки владельца добавляет участников (`role='member'`) в одной транзакции.
- UI: в модалке — поиск людей с чипами выбранных, кнопка «Создать» неактивна без участников, подсказка «Добавьте хотя бы одного участника».
- Миграции не нужны.

### 3.2. Профиль чата
- Новые API:
  - `PATCH /chat/api/chats/{id}` — название, описание, аватар (владелец; админ/модератор — тоже).
  - `DELETE /chat/api/chats/{id}/members/{user_id}` — удалить участника (владелец; себя — «выйти»).
  - `POST /chat/api/chats/{id}/leave` — выйти (владелец не может, пока не передаст владение или не удалит чат).
  - `DELETE /chat/api/chats/{id}` — удалить чат (владелец или админ).
  - `POST /chat/api/chats/{id}/owner` — передать владение (P2).
- Права: владелец — всё; участник — читать/писать/выйти; админ/модератор — модерация (уже есть удаление сообщений).
- UI: тап по шапке чата → экран «Профиль чата»:
  - аватар (загрузка как у пользователя, `POST /account/api/avatar`-подобно → для чатов новое поле уже есть),
  - название/описание с инлайн-правкой,
  - список участников с бейджем **«владелец»** и ролями,
  - «Добавить участников» (тот же поиск, что и в создании),
  - «Выйти из чата» / «Удалить чат» (красным), «Очистить историю» (P2).
- Миграции не нужны (все поля есть).

### 3.3. Группы и каналы
Нужна миграция (`00XX_chat_types.sql`):
- `chats.kind` → добавить `group`, `channel` (в SQLite CHECK-констрейнт меняется пересозданием таблицы; безопаснее добавить новый столбец `chat_type` со значением по умолчанию и оставить `kind` для совместимости).
- `chat_members.role` → `owner` | `admin` | `member` | `subscriber`.
- Новые поля: `username` (публичная ссылка), `is_public`, `slow_mode_seconds`, `pinned_message_id`, `history_visible` (история для новых).
- Новая таблица `chat_invites`: `code`, `chat_id`, `created_by`, `expires_at_ms`, `max_uses`, `uses`, `requires_approval`.
- Новая таблица `chat_join_requests` (P2): `chat_id`, `user_id`, `status`.
- Сервис: `create_chat(kind=...)`, права на постинг (в канале — только админы), подписка/вступление, приглашения, pin, slow mode, заявки.
- UI: переключатель «Группа / Канал» при создании; в канале композер только у админов, у остальных — «Подписаться»/«Отписаться», счётчик подписчиков; в группе — «участники».
- Дополнительно (как в ТГ): канал можно связать с группой комментариев (P3).

## 4. Что ещё стоит взять у Telegram (по приоритетам)

### P1 — заметно улучшает повседневный чат
- **Ответы (reply)**: цитата сообщения в композере и в ленте.
- **Пересылка** сообщений в другой чат.
- **Закреплённые сообщения** (pin + плашка сверху).
- **Реакции** на сообщения (👍 ❤️ 😂 — счётчик).
- **Упоминания @логин** с подсветкой и списком.
- **Поиск по сообщениям** внутри чата и по всем чатам.
- **Непрочитанные**: бейджи в списке чатов, счётчик, «прочитано до».
- **Черновики** сообщений на чат (сохраняются при переключении).
- **Mute/архив чата**, закрепление чатов в списке.
- **Удаление истории** у себя (не у всех).

### P2 — социальные и управленческие фичи
- **Роли админов и права** (добавлять участников, закреплять, удалять сообщения, банить, менять профиль).
- **Приглашения по ссылке/коду** с лимитом и сроком, «одобрение заявок».
- **Slow mode**, **история для новых участников**, «только админы пишут».
- **Блокировка пользователя** и «пожаловаться» (reports уже есть — связать с чатом).
- **Передача владения** чатом.
- **Аватар чата** (поле есть — нужен только UI + загрузка).
- **Профиль участника из чата** (уже есть модалка профиля — добавить «написать в личку»/«забанить»).
- **«Кто онлайн»** в шапке чата (у нас есть `/realtime/online`).
- **Опросы** (polls/quizzes).

### P3 — большие темы, если захочется «как в ТГ»
- **Папки чатов**, **темы оформления** (сейчас одна тёмная v5), **ночной/дневной режим**.
- **Стикеры/GIF**, **стикерпаки**.
- **Геолокация**, **контакты**, **живые местоположения**.
- **Боты** и мини-приложения (в наших условиях — плагины/скрипты на сервере).
- **Секретные чаты** (E2E) — на RPi без HTTPS не имеет смысла.
- **Звонки** (аудио/видео) — WebRTC, требует HTTPS + TURN.
- **Статистика канала** (просмотры, репосты, графики).
- **Расписание сообщений**, «напомнить о сообщении», «избранное» (Saved Messages).
- **Медиа-альбомы**, **кружки/видеосообщения**, **аудио-плеер с плейлистом**.
