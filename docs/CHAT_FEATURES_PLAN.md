## Что берём у Telegram (сверка)

P1: ответы, пересылка, закреплённые, реакции, упоминания, поиск по сообщениям, непрочитанные, черновики, mute/архив/закрепление, «удалить историю у себя» — всё в фазе 4.

P2: права админов, приглашения с лимитом, заявки, slow mode, история для новых, блокировка, жалобы, передача владения, аватар чата, «кто онлайн», опросы — фазы 3 и 5.

P3 (не делаем сейчас): папки, темы, стикеры/GIF, геолокация, боты, статистика канала, расписание, избранное, альбомы, кружки, звонки, секретные чаты.
