# Cardputer Client

Клиент Local Chat для M5Cardputer (ESP32-S3).

- Основное целевое устройство: обычный Cardputer (v1.1).
- Cardputer-Adv — вторичное, отдельная сборка только при подтверждённой разнице.

## Стек

- PlatformIO + Arduino framework + M5Unified / M5Cardputer.
- Транспорт (сменный, UI от него не зависит):
  - Wi-Fi 2.4 ГГц → HTTP API + WebSocket `/realtime/chat/{chat_id}` (основной);
  - ESP-NOW v2 (до 1470 байт) → мост M5Stamp S3 у RPi (второй этап).
- Авторизация: сопряжение по 6-значному коду (веб → устройство), затем `device-session` c секретом устройства.
- Язык интерфейса: русский, английский — переключателем в настройках.

## Порядок разработки (bring-up + этапы)

1. `bringup` — только экран, клавиатура и serial-лог. Проверка на железе.
2. `net` — подключение к Wi-Fi `local-chat`, `GET /health`, статус на экране.
3. `pair` — генерация device_id, запрос кода сопряжения, ввод кода в вебе, получение session_token.
4. `chat` — список чатов, лента, ввод и отправка, приём по WebSocket.
5. `content` — блог, поддержка, «о проекте».
6. `settings` — яркость, таймаут сна, уведомления вкл/выкл, язык, режим связи (хранение в NVS).
7. `notify` — уведомления о новых сообщениях (RGB LED, звук).
8. `espnow` — транспорт ESP-NOW через мост M5Stamp S3 (после рабочего Wi-Fi-клиента).
9. `repeater` — пункт «Ретранслятор» в настройках (по умолчанию выключен).

Правило: следующий этап не начинается, пока предыдущий не подтверждён на устройстве.

## Известные грабли (из прошлого опыта)

- Неверные флаги сборки (PSRAM `BOARD_HAS_PSRAM`, `qio_opi`) на плате без PSRAM → краши и «мёртвый» экран.
- Несовпадение версии M5Unified/M5Cardputer и ревизии устройства.
- USB CDC/лог: без правильных `ARDUINO_USB_*` флагов serial-лог не виден, и кажется, что «ничего не работает».
- Разные ревизии Cardputer / Cardputer-Adv: пины клавиатуры и версия библиотеки должны соответствовать.
- USB-Serial-JTAG не сбрасывается обычным RTS — после прошивки использовать `--after watchdog_reset` (добавлено в `upload_flags`).
- Вход в download mode: питание OFF → зажать G0 (маленькая кнопка у USB-C) → питание ON → через ~3 сек отпустить G0.

## Состояние

- bringup собран и залит на устройство (PlatformIO, espressif32 6.13.0, Arduino core 3.2.0 / IDF 5.4).
- Подтверждено на железе: экран, ввод (буквы, Enter, Del, Tab, Fn), модификаторы SHIFT/CTRL/OPT/ALT, serial-лог, heartbeat, свободный heap ~360 КБ.
- `net` подтверждён на железе: подключение к Wi-Fi `local-chat`, IP по DHCP `192.168.4.16`, RSSI −44 dBm, `GET /health` → HTTP 200 (`local-chat-server`, prod), heap ~271 КБ.
- Следующий этап: `pair` — сопряжение по 6-значному коду (требует доработки сервера).
