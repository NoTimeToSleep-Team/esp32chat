# LC Firmware

Прошивки аппаратных клиентов Local Chat.

## Статус

- Архитектура сервера: RPi-Only, транспорт клиентов — Wi-Fi (HTTP + WebSocket).
- Активные целевые устройства: **M5Cardputer** (первый приоритет), далее M5StickC Plus 2, T-Embed CC1101, Flipper Zero.
- Раньше папка `firmware` была битой git-ссылкой (submodule без объектов). Исходников старых прошивок нет.
- ESP-NOW / mesh: не входит в первый этап; рассматривается отдельно после рабочего Wi-Fi-клиента.

## Структура

- `cardputer/` — PlatformIO-проект клиента для M5Cardputer / Cardputer-Adv.
- `shared/` — общий код клиентов (протокол, API-клиент), если появится.

## Правила

- Каждая версия прошивки сначала собирается локально, затем проверяется на реальном устройстве.
- Неподтверждённые аппаратные проверки не заявляются как выполненные.
- Перед UI обязательно проходит bring-up: экран + клавиатура + serial-лог.
- Один шаг = одна проверяемая функция (сеть, сопряжение, чат и т. д.).
