Устройство
Каталог устройств
Портативный клиент Local Chat: чаты, блог и поддержка прямо с устройства. Работает по Wi-Fi внутри сети сервера.
Установка
Скачайте прошивку из релиза и прошейте устройство по инструкции из архива.
Первичная привязка
Включите устройство, дождитесь экрана сопряжения и введите его 6-значный код в разделе «Устройства».
Смена комбинации входа
Новая комбинация задаётся на самом устройстве и подтверждается на сервере.
