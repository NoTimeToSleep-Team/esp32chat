# web-test — тестовая версия интерфейса (только для проверки)

Тёмный мобильный интерфейс в стиле «Пачка» (по трём фото от 15.10.2026):
список чатов, экран чата, профиль. Это **демонстрационный макет** с
тестовыми данными — он не связан с реальным API сервера.

## Что это

- один самодостаточный файл `index.html` (весь CSS/JS внутри, без внешних
  зависимостей);
- экраны переключаются: `#/chats` (по умолчанию), `#/chat`, `#/profile`;
- в чате можно отправить сообщение — оно добавится локально (демо);
- кнопки, которых нет в макете, показывают подсказку «Тестовая версия…».

## Как включить на сервере

```bash
sudo bash enable.sh     # сохранит рабочий интерфейс в templates/index.html.orig и подменит главную
```

Портал: `http://<адрес-сервера>:18080/` — теперь отдаёт тестовый интерфейс.

## Как вернуть рабочий интерфейс

```bash
sudo bash disable.sh    # восстановит templates/index.html из .orig
```

Перезапуск сервиса не нужен: главная страница читается при каждом запросе.

## Важно

- это временная тестовая версия, не релиз: версия продукта не меняется;
- рабочий интерфейс не изменяется — он лежит в `templates/index.html.orig`;
- реальные страницы (`/admin`, API, `/health`) не затронуты.
