# web-test — новая версия интерфейса (полноценная, работает с реальным API)

Тёмный мобильный интерфейс в стиле «Пачка» (по трём фото от 15.10.2026),
адаптированный под все основные вкладки Local Chat. В отличие от первого
демо-макета эта версия **работает с реальным API сервера** — данные живые
(чаты, сообщения, блог, обращения, устройства, аккаунт).

## Что работает на реальных данных

- **Вход**: логин/пароль, регистрация, гость, выход; сессии совместимы с
  основным интерфейсом (те же ключи `lc_session_token` / `lc_user`).
- **Чаты**: список, непрочитанные, закреплённые, «без звука», архив,
  черновики (фильтр — в меню «…»; текст черновика восстанавливается в поле
  ввода при возвращении в чат), фильтры-квадраты (Личные / Важные / О проекте),
  поиск по чатам и людям, создание группы/канала, присоединение по ссылке/коду,
  личка.
- **Чат**: история с подгрузкой «Показать раньше», отправка текста и
  вложений (фото/файлы/аудио), голосовые (нужен HTTPS), ответы, пересылка,
  реакции, опросы с голосованием, закрепление сообщений (тап по плашке —
  переход к закреплённому сообщению с подсветкой), изменение и
  удаление своих, участники, ссылки-приглашения, очистка истории, выход и
  удаление чата, отметка прочитанного, черновики.
- **Блог**: лента, пост целиком, публикация поста (только admin).
- **Поддержка**: обращения с типом — Проблема (баг), Идея, Другое (можно
  отправлять сколько угодно), переписка, вложения, статусы (admin), жалобы
  на пользователей (спам/оскорбления/мат/реклама/мошенничество/другое).
- **Устройства**: сопряжение по коду, мои устройства и отвязка, каталог,
  «у меня есть устройство», прошивка и инструкции из каталога.
- **Аккаунт**: профиль, фото-аватар (сжатие до 512px) и эмодзи-аватар,
  лимиты аккаунта, переход в админ-панель `/admin`, выход.
- **Привязка к устройству**: браузер получает постоянный ID устройства;
  администратор может заблокировать вход с устройства — блокировка
  срабатывает и в приложении, и в админ-панели, и при регистрации.
- **Упоминания**: автоподбор участников по `@`, подсветка упоминаний в
  сообщениях, тап по упоминанию открывает профиль пользователя.
- **Настройки чата и канала** (владелец/админ): название, описание, аватарка,
  приватность (приватный/публичный + `@username`), медленный режим, видимость
  истории; заявки на вход с кнопками «Принять/Отклонить».
- **Приватные группы и каналы**: в приватный чат нельзя зайти по ссылке-поиску —
  только по ссылке-приглашению или одобренной заявке.
- **Адаптация под устройства**: телефоны — одна колонка (с учётом «безопасных зон»
  и клавиатуры), планшеты и десктоп от 940px — двухпанельный режим (список чатов
  слева, чат справа, пустое состояние «Выберите чат слева»), телефоны в ландшафте —
  компактная шапка и больше места сообщениям.
- **О проекте**: версия берётся с сервера (`/health`).
- **Анимации**: короткие переходы экранов, шторок, списков, новых сообщений и
  нажатий — в приложении и админ-панели; при `prefers-reduced-motion`
  отключаются.
- **Поиск**: ваши чаты, публичные чаты (подписка), люди (открыть личку),
  присоединение по ссылке или коду.
- **Языки**: переключатель RUS / ENG — на экране входа и в аккаунте; выбор
  запоминается, при первом входе язык определяется по языку браузера
  (русский браузер — русский интерфейс, остальные — английский). Админ-панель
  тоже двуязычная: кнопка RU/EN в шапке и на экране входа.

## Отличия интерфейса от первого макета

- поиск — овальная строка в шапке чатов (как в Telegram), открывает экран
  поиска; отдельной круглой кнопки больше нет;
- на экране входа вместо списка преимуществ — раскрывающийся блок «О проекте»;
- скругления уменьшены: карточки, поля и кнопки стали чуть строже; овальными
  остались поиск, чипы и нижняя навигация;
- квадраты «Личные / Важные / О проекте» — часть ленты: прокручиваются
  вместе со списком; первые два работают как фильтры, третий открывает
  экран «О проекте»;
- нижняя навигация — 4 вкладки; значок поддержки заменён на гарнитуру;
- исправлен низ экрана на телефонах со скруглёнными краями: safe-area для
  нижних панелей, единый цвет фона, без серой полосы над композером;
- интерфейс автоматически адаптируется под экран: на узких телефонах
  (до 380px) компактнее отступы и шрифты; на планшетах и ПК от 940px —
  двухпанельный режим (список чатов слева, чат справа).

## Управление (подмена главной портала)

- Включить: `sudo bash enable.sh` (рабочий интерфейс сохраняется рядом как
  `templates/index.html.orig`, повторный запуск бэкап не перезаписывает).
- Вернуть рабочий интерфейс: `sudo bash disable.sh`.
- Рестарт сервера не нужен: маршрут `/` читает шаблон при каждом запросе.

## Ограничения

- это новая версия в разработке: она временно подменяет главную страницу
  портала, но продукт (v0.1.10) и его рабочий интерфейс не изменяются;
- голосовые сообщения требуют HTTPS — на http-портале кнопка честно
  объясняет это и предлагает прикрепить аудиофайл;
- экраны админ-панели остаются отдельной страницей `/admin`.
