# web-test — тестовая версия интерфейса (только для проверки)

Тёмный мобильный интерфейс в стиле «Пачка» (по трём фото от 15.10.2026),
адаптированный под все основные вкладки Local Chat и наши кнопки:
вход, чаты, чат, блог, поддержка (обращения), аккаунт, устройства
(сопряжение по коду, мои устройства, каталог), о проекте, поиск.
Это **демонстрационный макет** с тестовыми данными — он не связан с
реальным API сервера.

## Что это

- один самодостаточный файл `index.html` (весь CSS/JS внутри, без внешних
  зависимостей);
- экраны переключаются по ссылкам: `#/login`, `#/chats`, `#/chat`, `#/blog`,
  `#/support`, `#/account`, `#/devices`, `#/about`, `#/search` и подэкраны
  (`#/post`, `#/ticket`, `#/newticket`, `#/device`, `#/newchat`);
- живые демо-действия: вход, отправка сообщения в чате, ответ в обращение,
  сопряжение устройства по 6-значному коду, отвязка устройства, поиск с
  фильтром, шторки действий на сообщениях и в меню чата;
- остальные кнопки показывают подсказку «Тестовая версия…».

Скриншоты (сняты с живой платы 15.10.2026): `screenshots/` — `login.png`,
`chats.png`, `chat.png`, `blog.png`, `support.png`, `account.png`,
`devices.png`, `about.png`, плюс проверка живых действий:
`chat-send.png`, `devices-pair.png`, `search.png`.

## Как включить на сервере

```bash
sudo bash enable.sh     # сохранит рабочий интерфейс в templates/index.html.orig и подменит главную
```

Портал: `http://<адрес-сервера>:18080/` — теперь отдаёт тестовый интерфейс.

## Как вернуть рабочий интерфейс

```bash
sudo bash disable.sh    # восстановит templates/index.html из .orig
```

Перезапуск сервиса не нужен: главная страница читается при каждом запросе.

## Важно

- это временная тестовая версия, не релиз: версия продукта не меняется;
- рабочий интерфейс не изменяется — он лежит в `templates/index.html.orig`;
- реальные страницы (`/admin`, API, `/health`) не затронуты.
