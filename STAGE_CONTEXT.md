## Цель этапа

Выпустить первый публичный релиз v0.1 серверной части (без устройств):

- установка на Raspberry Pi 4/5 (Pi OS 64-bit, Bookworm+) в 1–2 команды через curl;
- красивый мастер настройки (whiptail, schema-driven, часть установки);
- исключить нерабочие функции, чтобы сервер стал рабочим;
- релиз на GitHub (pre-release) с релизным тарболом и sha256.

## Что одинаково для всех подэтапов этапа

- v0.1 включает только `server/`; устройства, прошивки, bridge — вне релиза, их код не трогаем.
- Установщик и мастер — schema-driven: настройки в `server/setup/settings-schema.json`, скрипты generic (новые поля без правки скриптов).
- Мастер запускается сразу после установки; повторно — `lc setup`.
- Дефолты: порт `18080` (меняется), SSID `LC-Hub` (меняется), AP включена, регистрация свободная.
- Раскладка: `/opt/local-chat-server`, служебный юзер `localchat`, systemd `local-chat-server`.
- v0.1 — только чистые установки; старая живая плата (`/home/gamecat/lc-server`) остаётся как есть, миграция — отдельно после v0.1. _(ожидает явного подтверждения)_
- Версия релиза `v0.1.0`; публичный цикл — схема `v0.1.x` (внутренний исторический формат — `v1.00.xx`).
- Все результаты — только реально выполненные; непроверенное помечается честно.
